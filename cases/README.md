# All cases

Every case the site shows, one file each, exported from the code the site runs. The site itself reads `js/cases.js` (built-in cases) and `data/cases-extra.js` (cases added through the admin page); editing these JSON copies does not change the site. To change a case, upload its JSON on `admin.html`, then download the new `cases-extra.js`.
